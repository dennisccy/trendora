# Project story so far

Trendora is a market-leadership ranking tool that shows traders which scoring signals have genuinely earned their confidence labels — through rigorous out-of-sample testing, not in-sample curve-fitting.

## How it has grown

Trendora's first fifteen iterations built the trust layer itself — honest "Proven"/"Not yet proven" badges, an auditable evidence page, a private testing ground, and six certified trading edges — before iterations 16 and 17 deepened the underlying history to thirty years, adding matching stock-index and volatility data, each honestly labeled by its source.

Iteration 18 then widened the tracked company list from about 120 to several hundred and applied that deeper history everywhere. Every previously-certified trading edge honestly failed re-testing on the new data — evidence now reads "not yet proven" instead of a stale number, the system working as intended, not a step backward — but the same change briefly crashed the stock list when sorting by "Sector."

Iteration 19 fixed that crash at its root — sector sorting and filtering now works for every company, with a plain "Unassigned" label where no sector is on file — fixed a memory problem on the Data page that could freeze the app after a restart, and added a safety net so a future unexpected error shows a calm retry message instead of wiping out the whole app.

Iteration 20 turned to the Data Manager page: the "Fetch" button now keeps the entire company list (not just a smaller reference set) up to date, the now-redundant "Expand universe" option is gone, and the page's daily coverage calendar uses two clearly separate colors for "data exists" versus "already scored" instead of one shared, confusing color. A hands-on check confirmed it all works correctly and nothing else broke, but the team's usual automatic verification pass didn't finish this round — the site was briefly unreachable at the moment it ran — so the update is built and believed correct but not yet officially signed off. Next: finish that check, then return to re-earning "Proven" status for the retired trading ideas on the deeper history.

## What it can do today

The product lets users browse a leaderboard of hundreds of companies with up to thirty years of price history each, sort and filter by sector (with an honest "Unassigned" label for unmapped companies), and switch a stock's chart between a recent and full-history view. It shows an honest, auditable evidence status — currently "not yet proven" pending re-certification — on every score and past trading idea, tied to the current market regime, and lets users browse the company list as it looked on any past date. Unexpected errors now show a contained message instead of a blank screen.
