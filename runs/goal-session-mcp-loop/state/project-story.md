# Project story so far

Trendora is a market-leadership ranking tool that shows traders which scoring signals have genuinely earned their confidence labels — through rigorous out-of-sample testing, not in-sample curve-fitting.

## How it has grown

Trendora's first fifteen iterations built the trust layer itself — honest "Proven"/"Not yet proven" badges, an auditable Evidence page, a private testing ground, and six certified trading edges — before iteration 16 began a 30-year history upgrade (pausing for a human decision when a data provider balked) and iteration 17 completed it with matching index and volatility history, each honestly labeled by source.

Iteration 18 then threw the switch: history reached back 30 years and the tracked universe grew from about 120 companies to several hundred, every one of the seven previously-certified edges honestly failed re-testing on the deeper history (so evidence now reads "not yet proven" everywhere instead of a stale number), and the same change briefly crashed the stock list when sorting by "Sector," caught immediately by testing.

Iteration 19 fixed that crash at its root — Sector sorting and filtering now works for every company, with a plain "Unassigned" label for the roughly 4-in-5 lacking a sector on file — fixed a Data-page memory problem that could freeze the app after a restart, and added a safety net so a future unexpected error shows a calm retry message instead of wiping out the app.

Iteration 20 turned to the Data Manager page: the "Fetch" button now keeps the entire company list (not just a small reference set) up to date, the redundant "Expand universe" option is gone, and the page's daily-coverage chart now uses two clearly separate colors for "data exists" versus "already scored." A manual spot-check confirmed it all works correctly and nothing else broke, but the team's usual automatic verification pass didn't finish this round — the app was briefly unreachable when it ran — so the improvement is built and believed correct but not yet officially confirmed. Next up: finishing that verification, re-earning "Proven" status for the retired trading ideas on the deeper history, and showing the newly-added decades of market-index history.

## What it can do today

The product lets users browse a leaderboard of hundreds of companies with up to 30 years of price history each, sort and filter by sector (with an honest "Unassigned" label for unmapped companies), and switch a stock's chart between a recent and full-history view. It shows an honest, auditable evidence status — currently "not yet proven" pending re-certification — on every score and past trading idea, tied to the current market regime, and lets users browse the company list as it looked on any past date. Unexpected errors now show a contained message instead of a blank screen.
