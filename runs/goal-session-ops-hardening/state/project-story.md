# Project story so far

Trendora ranks stocks with explainable, evidence-checked signals — this chapter is about making the running app itself trustworthy day to day: fast, honest about its own state, and resilient under heavy background work.

## How it has grown

Early rounds removed a hidden backfill limit, moved slow calculations to run once at ingest instead of live, added a live status badge, fixed a cluster of low-memory crashes, and cut background-refresh memory 71% with identical numbers. Later rounds proved a deliberately-induced memory failure degrades cleanly, fixed slow price-loading, and repaired a broken automatic recheck that had let some features go unverified. One round found a single price request could hang forever and memory could run out during a heavy calculation, prompting the owner to raise the app's protective memory limit.

The next round caught the true cause of a different freeze: a slow bookkeeping step that was re-scanning 26 years of stock-eligibility history every time even one new day of data was added — though the freeze got worse before it got better, with the app going silent for over 20 minutes. The round after built the fix for that bookkeeping step, but the live database had no genuinely new day left to test it on — every remaining gap is an old one — and the app went dark again anyway, this time for about 42 minutes.

This latest round bounded two more of the exact memory-hungry spots feeding that outage. For the first time in five rounds, the app did not run out of memory once — even under the heaviest test load anyone has thrown at it — and the long dark-outage problem did not recur either. Along the way the team also fixed a separate snag: a backfill request with genuinely nothing new to add used to sit for fifteen minutes before finishing; it now finishes in seconds, and the Evidence page now loads almost instantly after a restart instead of taking nearly three minutes. The round's headline promise — the Evidence page staying fast even while a data job is running — is still not delivered: it can take over two minutes to load even with nothing else running. And because the one browser check this round ran was taken before two later fixes landed, most previously-working capabilities couldn't be freshly re-confirmed, so several are now marked "needs a fresh look" rather than broken — the app was finally tested properly, not made worse. Two capabilities remain solidly proven: viewing backtest results from storage, and an honest notice whenever the app is computing something in the background. Closing out the memory story and making the Evidence page fast after a data job are the team's next targets.

## What it can do today

The product lets users browse stock rankings, sector and theme views, backtests, and all five research tools. Two things are solidly confirmed working right now: viewing backtest results without ever waiting for a live recalculation, and seeing an honest notice when the app is crunching numbers in the background. Accepting a backfill request of any size and explaining honestly when nothing needed fetching, showing a clear boot/crash status badge, keeping pages loading only what they need, and staying responsive during heavy background work all mostly work today, but need a fresh, up-to-date check before they can be called fully confirmed again. Bringing in a genuinely new day of price data remains unreliable, and the team knows exactly which code spots are still responsible.
