# Project story so far

Trendora ranks stocks with explainable, evidence-checked signals — this chapter is about making the running app itself trustworthy day to day: fast, honest about its own state, and resilient under heavy background work.

## How it has grown

Early rounds removed a hidden backfill limit, moved slow calculations to run once at ingest instead of live, added a live status badge, fixed a cluster of low-memory crashes, and cut background-refresh memory 71% with identical numbers. Later rounds proved a deliberately-induced memory failure degrades cleanly, fixed slow price-loading, and repaired a broken automatic recheck that had let some features go unverified. One round found a single price request could hang forever and memory could run out during a heavy calculation, prompting the owner to raise the app's protective memory limit.

A subsequent round caught the true cause of a different freeze — a slow bookkeeping step re-scanning 26 years of stock-eligibility history on every new day of data — and the round after that built the fix, though the app went dark again for about 42 minutes along the way because the live database had no genuinely new day left to test the fix on. The round after that bounded two more memory-hungry spots feeding that outage: for the first time in five rounds the app did not run out of memory once, even under the heaviest load anyone had thrown at it, and the multi-minute dark-outage problem did not recur.

This latest round finished the headline job left over from that one: the Evidence page, which used to freeze for over two and a half minutes any time unrelated data changed anywhere in the app, now answers in about a hundredth of a second — showing an honest amber "Refreshing" badge on any panel serving slightly-behind numbers while a fresh version catches up in the background. An independent check proved the underlying numbers stayed exactly correct throughout, and along the way it caught and fixed a subtler bug where the fix itself could double up its own background work. But the round's one process failure canceled out most of its credit: the automatic check that re-confirms all eight core capabilities was run early, then the code changed three more times afterward, so it never ran again before the round ended — meaning almost nothing could be freshly re-confirmed working, for the second round in a row. Bringing in one old day of missing price history still never finishes; that, plus finally re-running the full check, are next.

## What it can do today

The product lets users browse stock rankings, sector and theme views, backtests, and all five research tools. Two things are solidly confirmed working right now: viewing backtest results without ever waiting for a live recalculation, and seeing an honest notice when the app is crunching numbers in the background. Accepting a backfill request and explaining when nothing needed fetching, showing a boot/crash status badge, keeping pages loading only what they need, and staying responsive during heavy background work all likely still work today, but need a fresh, up-to-date check before they can be called fully confirmed again — none has had one in two rounds. Bringing in a genuinely new day of price data remains unreliable, now for a fourth round running, and the team knows exactly which code spot is responsible.
