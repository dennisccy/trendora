# Project story so far

Trendora is a local-first, research-only US equity leadership scanner — a decision-support workstation that ranks the market after the close and earns the user's trust with forward-tested evidence rather than ever shouting "buy."

## How it has grown

Trendora arrived already substantially built — a dark dashboard ranking US stocks, sectors, and themes after the close, every score explained and every idea showing what would prove it wrong. Early passes closed the original gaps: one shared date control, click-through from any forward-tested return to the names behind it, a Data Manager that backfills without inventing numbers, matching scores across pages, a restart-proof watchlist, and fast snapshot loads — finishing all nineteen original journeys.

The owner then asked for more. Charts learned to keep drawing past a chosen date to today while scores still reflected only what was known then. A Research section grew into a Factor Lab (split by market mood, blended across signals, extended to a volatility family), a Setup & Pattern Lab studying every past occurrence, and a synthesis capstone linking any finding to the filtered leaderboard and on to a stock's scorecard. A re-scope made the data-blocked items non-halting and gave Research its own all-history to as-of-date toggle. Real data import came next: a source picker with session-only API keys (never saved), a chunked import engine that pauses and resumes across restarts, and an Expand-universe job that screens a 548-name candidate pool and writes exactly who passed and who was omitted with the reason.

Later iterations rounded out the Data Manager surface. Coverage gained per-symbol detail, plain-language definitions, and a clear "universe vs symbols" distinction. A Missing-data diagnostic panel flags every universe member with too little history or internal gaps, with a one-click pull-missing button. A unified Unfinished-imports panel groups every paused, partial, and failed import in one place, each with Resume, Retry, and Remove controls. A seed-safe Remove-data panel lists exactly the user-added bars to be deleted and their cascading dependents before anything is touched.

Iteration 26 built the final enabler: an offline "seed" import source (activated only in the test harness) and a reproducible fixture database containing deliberately gapped stocks so the browser checker can run real pull and expand flows to completion without any live internet connection. It also fixed the one remaining UX gap on the Resume control — a failed resume now shows a clear inline error and keeps the row visible instead of appearing to do nothing. All four target features are now code-complete and 610-tests-green, but the browser walkthroughs have not been captured yet because the test harness was not wired up during this check cycle. That single wiring step is all that stands between the current state and goal completion.

## What it can do today

The product lets users see the day's market at a glance; browse ranked stocks, sectors, and themes; open any stock for a plain-English scorecard; rewind the whole app to any past date; read forward-tested evidence on the Backtest page; explore Research labs by factor decile, market mood, signal blend, volatility family, event study, and all-history or point-in-time toggle; travel from any finding to the filtered leaderboard and on to a stock detail; keep a restart-proof watchlist; read every label in the glossary; import from a selectable data provider with a session-only key; run large imports in visible batches that pause and resume; grow the universe via the Expand job; read a labelled coverage panel with a per-symbol table; see a diagnostic panel that names every data gap; and manage every incomplete import in one unified panel with Resume, Retry, and Remove actions.
