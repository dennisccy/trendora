# Project story so far

Trendora is a local-first, research-only US equity leadership scanner that helps you understand the market clearly — ranked stocks, explainable scores, walk-forward evidence, and a full research lab — without placing orders or touching real money.

## How it has grown

The product arrived at this session already carrying a full, verified set of capabilities: a live dashboard with a market-regime score, a ranked stock leaderboard filterable by sector or pattern, individual stock pages with a price chart and a plain-language breakdown of every score component, walk-forward backtest evidence with control groups, a Factor Research Lab, a persistent watchlist, and a Data Manager that handles imports, coverage gaps, and interrupted jobs.

Iterations 1 through 14 built out the full surface in waves. Dates display as YYYY-MM-DD everywhere; the dashboard gained a major-indexes chart with regime colour bands; the leaderboard gained column sorting, a live search box, and theme filtering with expandable member stocks as dated new-tab links; the Sectors leaderboard shows every ETF named and mapped to its universe; multi-date backfill runs roughly four times faster in parallel with per-stage timings; the Research Lab connects every sample-count chip to the exact stored observations; the import pipeline gained stage-aware resume, instant run history, per-date failure isolation, a per-date availability heatmap, and a live as-of calendar popover; and the event study switched to an overlap-honest first-trigger episodes default with a one-click toggle to pooled view. The J-55–J-67 extension brought samples sort/filter, N= new-tab chips, a glossary catalog with tooltips across all dense surfaces, and a jobs pipeline overhaul. The goal was declared achieved after iter-14.

Iterations 15 and 16 extended the product in-place. Multi-month backfill jobs that previously crashed mid-run now complete reliably; data removal became a deliberate, range-scoped action with a confirmation dialog. The availability heatmap became easier to read — day numbers stand out in every cell, months are ordered newest-first, two months appear per row — and the as-of calendar gained keyboard stepping so arrow keys jump between snapshot dates.

Iterations 17 and 18 added the next batch of polish. The heatmap received a multi-hue colour scale (dark slate through blue, cyan, teal-green, green, amber) with a legend, and the stock-detail price chart gained a crosshair hover box showing exact date, OHLCV, percentage change, and each moving-average value for any bar, with a clear "after as-of (display only)" label on forward bars. Iter-17 shipped the code but a browser environment outage prevented live confirmation; iter-18 restored the environment and verified both features 9/9.

Iteration 19 fixed one of the most noticeable rough edges: opening a historical date link used to briefly flash today's figures before switching to the past date. That flash is now gone — the correct data appears from the very first paint, whether you deep-link, reload the page, open in a new tab, or navigate in-app. A smaller but welcome companion change made the Dashboard's market-indexes chart open on the full available history (back to 2021) instead of the previous six-month default window. Both changes passed all browser checks, and the critical single-date-selector guarantee — that no feature introduces a second date control — was re-confirmed with post-hydration URL assertions across six different arrival paths.

## What it can do today

The product lets users see today's market regime and top-ranked stocks on a dashboard whose indexes chart now opens on the full available history by default; open any stock for a full explainable score breakdown with a regime-banded price chart and a per-bar hover box showing exact OHLCV and moving-average values; step back to any past snapshot date using a calendar or arrow keys, with historical data appearing immediately and without any flicker; share or open any historical link in a new tab; sort and search the stock leaderboard by any column; filter by theme and expand each theme's member stocks as dated new-tab links; browse the Sectors leaderboard with every ETF named and mapped to its universe; run walk-forward backtest evidence with control groups and return attribution; explore factor effectiveness and overlap-honest event studies; click any sample count to open the exact stored observations; save stocks to a watchlist; and manage price-data imports with live progress, instant run history, stage-aware resume, per-date failure isolation, a compact multi-hue availability heatmap, reliable multi-month backfill, and a deliberate range-scoped data-removal flow.
