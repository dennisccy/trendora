# Project story so far

Trendora is a local-first, research-only US equity leadership scanner — a decision-support and evidence-tracking platform that ranks stocks, explains every score, and proves its own usefulness through walk-forward historical evidence, without placing orders or touching real money.

## How it has grown

The product arrived at this session already carrying a full, verified set of capabilities: a live dashboard with a market-regime score, a ranked stock leaderboard filterable by sector or pattern, individual stock pages with a price chart and a plain-language breakdown of every score component, walk-forward backtest evidence with control groups, a Factor Research Lab, a persistent watchlist, and a Data Manager that handles imports, coverage gaps, and interrupted jobs.

Iterations 1 through 14 built out the full surface in waves. Dates display as YYYY-MM-DD everywhere; the dashboard gained a major-indexes chart with regime colour bands; the leaderboard gained column sorting, a live search box, and theme filtering with expandable member stocks as dated new-tab links; the Sectors leaderboard shows every ETF named and mapped to its universe; multi-date backfill runs roughly four times faster in parallel with per-stage timings; the Research Lab connects every sample-count chip to the exact stored observations; the import pipeline gained stage-aware resume, instant run history, per-date failure isolation, a per-date availability heatmap, and a live as-of calendar popover; and the event study switched to an overlap-honest first-trigger episodes default with a one-click toggle to pooled view.

Iterations 15 through 21 added further polish. Multi-month backfill jobs complete reliably; data removal became a deliberate, range-scoped action with a confirmation dialog; the availability heatmap gained a multi-hue colour scale with a legend; the stock-detail price chart gained a crosshair hover box; opening a historical date link no longer flashes today's figures before switching; the dashboard's market-indexes chart was changed to open on the full available history by default; and every stock now shows realized forward returns at five horizons alongside a Regime x Setup x Pattern ranked study with NA-last sorting, filter dropdowns, and correct drill-down counts.

Iterations 22 through 24 delivered research upgrades: the Stocks leaderboard header gained a live regime label and a ranked top-five themes strip with chip badges; the as-of panel gained always-visible back/forward stepping buttons, opt-in keyboard arrow keys, and year/month jump dropdowns; Themes and Sectors leaderboards gained five forward-return columns matching Backtest exactly. Iteration 25 fixed a subtle rendering quirk so historical date links show the correct data from the very first server render. Iteration 26 fixed the Expand-universe job's market-cap authentication so real market caps are fetched instead of silently failing, with a clear Resume affordance when the provider is temporarily unavailable.

Iteration 27 closed the universe-expansion loop and added downside-risk context everywhere. The Data page now shows a coverage diagnostic — a calm "all members present" note when the universe is fully covered, or an amber banner listing absent members — and a confirm-gated "Rebuild snapshots for current universe" button that clears and fully regenerates the snapshot set from scratch (the committed price seed is never touched). Every forward-return figure across the app — stocks leaderboard, stock detail, themes, sectors, backtest breakdowns, and research tables — is now paired with a matching max-drawdown read from the same walk-forward calculation, so users can see how far a position could have fallen in the worst stretch across each time horizon. The data correctness and backend suite are fully green; two small frontend display issues (column sort behaviour and colour grading intensity) remain for the next lean pass before the goal is declared achieved.

## What it can do today

The product lets users see today's market regime and a ranked top-five themes strip on the Stocks leaderboard header; step back to any past snapshot date using always-visible back/forward buttons, optional keyboard arrow keys, or the calendar popover with year/month jump menus; open any historical date link and see the correct data from the very first moment; open any stock for an explainable score breakdown with a regime-banded price chart, a per-bar hover box, and realized forward returns at five horizons alongside a max-drawdown figure for each horizon; sort and search the stock leaderboard by any column; filter by theme and expand member stocks as dated new-tab links; browse the Sectors leaderboard with every ETF named and mapped; see five forward-return and five max-drawdown columns on the Themes and Sectors leaderboards matching Backtest exactly; run walk-forward backtest evidence with control groups and average max-drawdown per breakdown group; explore factor effectiveness, an event study, and a Regime x Setup x Pattern ranked study with filter dropdowns and correct NA-last sorting; click any sample count to open the exact stored observations; save stocks to a watchlist; trigger a confirm-gated full snapshot rebuild from the Data page; and manage imports with live progress, stage-aware resume, per-date failure isolation, a multi-hue availability heatmap, reliable multi-month backfill, a deliberate range-scoped data-removal flow, and an Expand-universe job that properly authenticates with the data provider.
