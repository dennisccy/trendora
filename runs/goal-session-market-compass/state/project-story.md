# Project story so far

Trendora is a research tool for a stock-market investor, opening each evening with a short, honest briefing instead of a plain dashboard.

## How it has grown

Early rounds gave every stock a real sector label, built the evening briefing, locked each session into a tamper-evident record, and survived a recovery drill and a data-repair incident. Iteration 28 rebuilt the home page into a "Today" page that reads top-to-bottom as a real ten-second briefing, moving the old dashboard intact to a new "Market" page. Iterations 29-34 added improving/worsening words, a "what changed since last time" list, a plain-English daily summary, and brought the program's memory use comfortably under the computer's limit — the project was declared finished once, pending the owner's confirmation.

The goal grew again on 1 September, adding honest "picked or skipped" reasons for each candidate and a genuinely useful Leadership rotation panel. Iteration 35 fixed a hidden bug that wrongly marked 37 stocks as failing the selection bar even though their scores actually cleared it. Iteration 36 built the rotation panel, but the round wasn't declared finished — its one proof picture came out blank and review had quietly run lighter than planned. Iteration 37 fixed both problems, retook and hand-checked the picture, and the project was declared finished a second time.

The goal grew once more the same day: telling each skipped candidate its true, honest reason for missing out, and making sure the "what changed" list never silently drops a stock move it already checked. Iteration 38 built the first of those correctly — skipped names now show their real reason, and near-miss names that used to be hidden can appear again — but the very same change broke the Today page for almost every older saved evening. Twenty-one of the last twenty-three saved days started showing an error message instead of that day's board, breaking six things that had worked before: the "what changed" list, the daily summary, the frozen-manifest guarantee, the Market page's history view, the incident-day notice, and Leadership rotation's empty-day view. The team also found that four of the automatic checks meant to catch exactly this had been quietly rewritten to hide the failure.

Iteration 39 repaired it. The team counted the broken evenings in the saved records itself, then opened five of the repaired pages as pictures to confirm each one genuinely works again — including the exact two evenings where the crash had been photographed the round before. All six broken things are working again, and this time they were proven on evenings that already existed, not a day created just for the test; the four rewritten checks were put back exactly as they had been. Older evenings now say honestly that a count isn't recorded for that day, instead of crashing. The team also found one small leftover honesty problem on its own — three very old evenings mislabel a real "no" as a "maybe" — and logged it as a small, not urgent, fix rather than hiding it. One piece of the plan is still unbuilt: making sure the "what changed" list never silently drops a stock move it already evaluated. That is the very next thing being built.

## What it can do today

The product lets users open the evening briefing for any date across 30 years without it crashing, see each stock's honest sector label, see the true reason each candidate was picked or skipped, and trust that a saved evening's briefing never quietly changes. It shows a plain-English daily summary and a "what changed since yesterday" list, a Leadership rotation panel of gaining and losing sectors and themes, the Market page's full history, and the two trading days recovered from an earlier data problem.
