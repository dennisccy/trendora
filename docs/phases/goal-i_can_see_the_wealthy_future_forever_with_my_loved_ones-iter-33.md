## GOAL

The scanned stock universe becomes **point-in-time**: at any as-of date D the scored set is resolved per-D by a single new resolver that screens the candidate pool on price + ADV + ≥200-bar minimum-history from bars dated ≤ D, so an early date honestly shows fewer (or zero) names through a deterministic warm-up, a new Data-Manager membership timeline shows entries/exits/per-date size with honest survivorship + warm-up labels, and the backward-history extension is offered as a confirm-gated, data-walled non-halting flow.
