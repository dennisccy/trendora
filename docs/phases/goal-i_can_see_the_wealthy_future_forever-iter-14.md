## GOAL

Add the **Setup & Pattern Lab** (an event study) to the existing approved `/research` home: for a chosen setup or detected pattern, pool every historical occurrence across all immutable snapshots and report — per horizon — the forward-return **distribution** (mean / median / % positive / dispersion), **expectancy**, **MAE/MFE** (max adverse / favorable excursion from post-snapshot daily highs/lows), the **risk-adjusted** ratios (downside-only: return/downside-deviation and return/mean-|MAE| — never total vol), the **best exit-horizon** curve, and **by-regime** + **by-sector** slices, each with sample size `n` and honest NA. To make MAE/MFE possible, first extract and store the post-snapshot daily high/low **excursion path** on the append-only `forward_returns` table (computed once, lookahead-free, immutable), then read it verbatim in the read-only lab.
