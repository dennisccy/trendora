## What Was Built

- **`scripts/screen_universe.py`** (new, one-shot offline) — the universe screen + ingest tool:
  - `--build-pool`: fetches the **real S&P 500 + Nasdaq-100 constituents (+ GICS sectors) from
    Wikipedia**, unions them with the prior committed universe, writes the documented frozen candidate
    pool `data/seed/universe_pool.csv` (**548 candidates** — `503 sp500 + 13 nasdaq100-only + 32
    prior-only`). Already run + committed-ready.
  - `--screen` (default): fetches real EOD OHLCV (Yahoo chart, no key) + real market cap (Yahoo quote
    via the no-key cookie+crumb flow) for each candidate; applies the **config screen** from
    `universe.filters` (min price / min ADV-dollar-volume / min market cap); keeps **passers** as the
    universe; **logs + omits** any candidate that fails to fetch or falls below a threshold (never
    fabricates). Reuses already-committed price CSVs (SPY/ETFs/prior names) so only NEW names hit the
    network. Writes `data/seed/universe.json` (per-member screen-pass record), the new price CSVs, and
    refreshes `data/seed/meta.json`. Exposes a pure, unit-tested `screen_reasons(...)` predicate.
- **`scripts/apply_universe_to_config.py`** (new, one-shot) — rewrites `config.yaml`'s
  `universe.symbols`, `stock_sectors`, and (pruned) `themes` from `universe.json`, **preserving every
  section comment**, then re-loads + re-validates the config (every member has a sector; every theme
  member is in the universe; themes stay non-empty). Validated end-to-end on a config copy.
- **`config.yaml`** — added `methodology.universe_selection` (membership-rule prose + the three screen
  thresholds as live `ref`s into `universe.filters` — no re-typed numbers).
- **`app/config.py`** — new typed `UniverseSelectionCfg` on `MethodologyCfg`; the boot-time
  ref-resolution validator now also covers the universe-selection thresholds (an unresolvable ref fails
  the boot loudly).
- **`app/engine/methodology.py`** — `build_catalog` now emits a `universe_selection` payload (membership
  rule + thresholds resolved live + `resolved_size = len(config.universe.symbols)`). No literal added
  (stays clean for the no-magic-numbers contract).
- **`app/seed_loader.py`** — `load_universe_screen_record(seed_dir)` reads `universe.json`; the loader
  populates `Stock.market_cap` read-only from it (idempotent backfill; absent record ⇒ NULL/NA, never
  fabricated).
- **`app/engine/data_manager.py`** — `compute_coverage` now returns `universe_count`
  (= `len(config.universe.symbols)`, the same value `/api/methodology` reports — one source, no drift).
- **Frontend** — `/methodology` renders a new **Universe Selection** card (rule + the three thresholds,
  compactly formatted `$2B`/`$50M`/`$10` from the API values + resolved size); `/data` coverage shows a
  new **Universe** metric. Types added to `lib/api.ts` (`UniverseSelection`, `universe_count`).
- **Tests** — `tests/test_universe_screen.py` (new: pure screen predicate pass + 4 failure paths;
  universe-size single-source consistency across `/api/data` ↔ `/api/methodology` ↔ config; committed
  record passes-screen + matches-config + market-cap-from-storage, which assert once `universe.json`
  exists); `tests/test_methodology.py` (new: Universe Selection section present, live-ref, not a glossary
  entry).

  uses within-symbol returns/ratios, so a mixed-epoch seed is sound. SPY (the RS benchmark) is kept on
  its committed basis for both old and new names.
